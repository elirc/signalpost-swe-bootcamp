# M02 — Domain core

Make storage and query semantics explicit.

Target competencies: data modeling, storage design. Provisional target rubric level: 3. Learning: unassessed.

## Working knowledge

Choose indexes from access paths. High-cardinality labels multiply series and index cost. Time partitioning limits scans only when predicates align with partition keys. Aggregating averages requires carrying counts or sums, not averaging averages.

## Adversarial scenario

A daily chart combines an hour with 10 samples and an hour with 10000 samples. Find the misleading aggregate.

## Transfer assessment

Add a second tenant with overlapping labels and measure the same query again.

## Demo and defense

Present a reproducible demo and failure. Defend an alternative, a concurrency/failure/scale boundary and the first expected breaking point. On a miss, preserve correct software, complete the smallest exposing exercise, then reassess with a changed example.
