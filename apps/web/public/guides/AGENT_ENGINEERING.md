# Use AI without outsourcing your learning

Begin this sequence in U08, after you can implement and test a bounded feature yourself. Earlier, AI can explain a concept or give a hint in guided mode; the learner types and explains the code.

1. **Prepare context:** write goal, relevant files, input/output contract, non-goals and a verification command. Predict the hard part.
2. **Bound one task:** delegate a small refactor or a test fixture, not the competency you are currently trying to demonstrate independently.
3. **Review every change:** inspect the diff, run meaningful checks and explain a failure case with the patch closed.
4. **Reject plausible mistakes:** use a disposable copy for an agreed defective-patch exercise. Findings need a scenario, evidence and consequence.
5. **Integrate responsibility:** attribute the agent's contribution, resolve scope creep and write your own final PR explanation.
6. **Prove transfer:** implement a changed requirement without AI afterward. Record assistance honestly.

A delegation brief contains: goal; current revision; allowed files/actions; boundaries to preserve; excluded scope; test command and acceptance; timebox/stop condition; requested evidence. Broad autonomous scaffolding is suitable for preparing learning materials, not for claiming learner completion.

Reusable request: “Give one conceptual hint for this attempt. Do not write the assessed function. Here is the contract, my prediction, code, actual output and current hypothesis.” If a full solution is revealed, classify that attempt as guided and schedule a fresh independent variation.

Future automation that can deploy, send messages, spend money or alter real data needs explicit scope. The local practice exercises need none of those capabilities.
